# Vihaan 2025 🚀  
Website for **Vihaan 2025**, IEEE DTU's flagship 24-hour student-run hackathon.

---

## Overview
**VIHAAN** is a 24-hour hackathon that empowers budding programmers to craft tech solutions addressing real-world problems. Students participate in teams of up to 4 members across various tracks. Finalists earn cash prizes and exclusive goodies, enhancing both the experience and learning.

---

##  Built With
- **Frontend:** Next.js  
  - Optimized for **SEO friendliness**, ensuring strong presence in search results.
- **Quiz/Interaction Backend:** Go  
  - Fast, low-latency API for quiz sections and real-time participant interaction.
- **Devfolio SDK:**  
  - Seamless integration for registrations and submissions via Devfolio.
